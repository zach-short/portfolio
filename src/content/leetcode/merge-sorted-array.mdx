## Go Solution

```go
func merge(nums1 []int, m int, nums2 []int, n int)  {
    nums := nums1 
    for _, num := range nums2 {
        nums[m] = num
        m++
    }
    sort.Ints(nums)
    nums1 = nums
}
```
